TOHAIBA HOQUE — GRAPHIC DESIGNER PORTFOLIO

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html, or open it with VS Code and use Live Server.

FILES
- index.html: page content and project gallery
- style.css: colors, layout, responsive styling and animations
- script.js: mobile menu, scroll reveal and active navigation
- assets/: optimized WebP previews made from the supplied EPS artwork

PORTFOLIO PROJECTS
- Tropical Toucan Illustration
- Happy New Year 2027 lettering
- Cute Themed Icon Set
- Shopping Icon Set
- Geometric Folk Art Birds

CUSTOMIZE
- Change text in index.html.
- Change colors near the top of style.css in the :root section.
- Replace images in assets/ and update the corresponding image paths and alt text in index.html.
- Contact email: tohaiba07@gmail.com

NOTE
The original EPS files are not embedded; optimized WebP previews are included for fast website loading.
Google Fonts are loaded online. The page still works without them, using fallback fonts.
